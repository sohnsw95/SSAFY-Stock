# 백엔드 기여와 설계 판단

[프로젝트 개요](../README.md) · [화면](screens.md)

2026-10-15에 원본 변경 내용, 담당 기록과 MR 요약을 대조해 정리했습니다.
아래는 구현을 설명한 문서이며 비공개 소스의 복사본이나 실행 가능한 예제가 아닙니다.

## 1. 관심종목을 사용자 도메인으로 관리

**시기:** 특화 프로젝트, 2026년 3월.

등록 시 사용자·종목의 존재와 기존 등록 여부를 확인했습니다. 삭제는 사용자 ID와 종목 코드로 대상을 조회해 다른 사용자의 목록을 지우지 않도록 구성했습니다.
조회에서는 관심종목과 계좌 보유 정보를 연결해 응답했습니다. 이후 최대 3개 등록 조건을 추가했습니다.

단순한 개수 조회 후 저장만으로 동시 요청의 상한 보장을 증명할 수는 없습니다. 동시성 부하 검증 결과는 확인되지 않았습니다.

## 2. 커뮤니티 CRUD와 작성자 권한

**시기:** Theseus Remote Workspace 연동 후속 개발, 2026년 5월.

| 요청 | 구현한 조건 |
|---|---|
| 게시글 목록 | 종목 식별자 검증, 페이지 조회, 작성자·주주·좋아요 정보 결합 |
| 글·댓글 작성 | 필수 제목·본문 정리 및 검증, 대상 사용자·게시글 확인 |
| 글·댓글 수정·삭제 | 요청자 ID와 작성자 ID가 다르면 접근 거부 |
| 좋아요 | 기존 좋아요 존재 여부에 따라 추가 또는 삭제, 개수·본인 상태 반환 |
| 목록 정렬 | 최신순·좋아요순·댓글순·조회수순 선택 |

### 주주 배지와 목록 조회

주주 여부는 해당 종목의 보유 수량이 0보다 큰지로 판단했습니다. 목록에서는 작성자 ID를 모아 조회하고 사용자별 결과로 변환했습니다.
글마다 같은 작성자를 반복 조회하는 대신 묶어서 조회하는 구조를 사용했습니다. 전후 쿼리 수나 응답 시간의 실측 기록은 없어 개선율을 제시하지 않습니다.

### 화면과 JSON 이름 맞추기

주주 표시 필드는 `isShareholder`라는 이름을 계약으로 삼았습니다. DTO의 타입·직렬화 설정을 보완하고,
게시글 목록·상세·댓글 응답에서 해당 키가 나오며 다른 키로 바뀌지 않는지 확인하는 테스트를 작성했습니다.

### DDL과 기존 데이터베이스 반영

게시글·댓글·좋아요 테이블과 관계를 구성했습니다. 종목별 게시글, 게시글별 댓글의 조회 순서를 고려한 복합 인덱스를 추가했습니다.
기존 테이블에는 외래키·인덱스가 없을 수 있어 메타데이터에서 존재 여부를 확인하는 보정 SQL을 작성했습니다.
운영 DB 전체 마이그레이션의 무중단 수행이나 모든 데이터의 정합성 검증을 의미하지는 않습니다.

## 3. 배포 범위를 서비스 변경에 맞추기

후속 자산 요약 API에서는 보유 수량이 있는 포지션과 현재가를 결합해 평가액·손익·비중을 계산했습니다.
보유 종목 없음·계좌 없음·합계와 비중 계산을 다루는 테스트를 작성했습니다. `1e3dfb8`의 서비스·DTO·테스트에서 확인됩니다.
시세 누락 처리와 실제 부하 상황은 별도 검증 영역입니다.

특화 기간에는 Compose를 web/server/infra/monitoring으로 구분하고 Jenkins에서 변경 서비스를 선별했습니다.
Push·MR의 빌드·테스트 단계와 dev 배포 조건을 구분했습니다. 후속 연동에서는 stock_dev 관련 경로·배포 조건을 조정했습니다.

Jenkins의 하위 경로에서 발생한 crumb 403은 실행 prefix와 Nginx 전달 경로를 맞추는 방향으로 수정했습니다.
보안 검증을 우회한 해결로 설명하지 않습니다.

## 검증 범위와 팀 기여

- 작성자 권한 거부, JSON 직렬화, 좋아요 추가·취소·대상 부재 테스트 소스를 확인했습니다. 이번 문서 정리에서 서비스 테스트를 실행한 것은 아닙니다.
- 당시 CI 실행 결과, 부하 조건별 성능 수치, 좋아요·댓글의 동시성 보장 결과는 확인되지 않았습니다.
- 체결 executionId 중복 수정과 시세 수신 성능 변경은 다른 팀원의 변경으로 확인했습니다. 개인 기여에 포함하지 않습니다.
- 후속 운영에서 시세 미갱신을 구간별로 진단하고 재시작 후 수신·화면 갱신을 확인한 기록은 있습니다. 근본 원인은 확정하지 못했습니다.
